<objective>
Land the end-to-end Phase 1 verification gate: a smoke test script that proves every container reaches healthy state and every service responds to its `/health` endpoint after a fresh `bun run docker:up`. Update the NestJS bootstrap in both services to read PORT from the typed env layer (P1.7) and ensure a working `/health` controller exists in each service.

Purpose: Phase 1's claim is "zero-step bootstrap on a fresh clone" (REQ-INFRA-01). Without an automated smoke test, that claim is unverifiable — every later phase would have to manually re-run the stack to confirm Phase 1 still works. The smoke script also gives Phase 10 the seed for its CI pipeline (REQ-CI-02: CI runs `docker:up` + waits for health + tears down).

This plan has a **human-verify checkpoint** because the bootstrap test takes ~90 seconds and produces visible terminal output the human should eyeball for the "all green" signal — automated assertion alone is not sufficient when the entire system is wired together for the first time.

Output: An executable `scripts/smoke-health.sh`, a `/health` controller per service, env-driven bootstrap, and a documented checkpoint where the human confirms the full-stack smoke run.
</objective>
