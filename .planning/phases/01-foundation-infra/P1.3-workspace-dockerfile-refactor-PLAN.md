## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dockerfile base image → built artifacts | Floating tag can backdoor the supply chain |
| `bun install` inside container → npm registry | Transitive dependency tampering |
| Migration container → Postgres | Runs as superuser-equivalent inside DB; can DROP/ALTER anything |
| Runtime container → host network | `EXPOSE` declares intent; compose `ports` enables it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01.3-01 | Tampering | Bun base image | mitigate | Pin `oven/bun:1.3.11-alpine` exact; matches `.bun-version` from P1.1 |
