<objective>
Land the typed configuration layer for both services and the `.env.example` files that document every operator-tunable constant in one place. Materialize all 19 rows from REQUIREMENTS Open Configuration Values (Phase 1 ships them; Phase 3+ services start reading them). Zod parses `process.env` at boot — missing or malformed env values fail fast, not at first use.

Purpose: REQ-INFRA-05 forbids hardcoded business constants anywhere in the codebase. The ESLint `no-restricted-properties` rule (P1.6) bans `process.env` outside the config layer; this plan IS that layer. Without it, every later phase would have to re-invent env parsing.

REQ-DOM-05 (wallet balance never negative) is anchored here at the env level: `INITIAL_BALANCE_CENTS` is the canonical source for the seed value, defaulting to `100000` (1000.00 CRD per REQ-WALL-03). The actual Postgres `CHECK (balance_cents >= 0)` migration ships in Phase 3; this plan establishes the operator surface that the Wallet service will consume.

Output: Two service-side `defaults.ts` files, three `.env.example` files (root + 2 service), two gitignored `.env` files seeded from the example, and a test file proving the shared schema's parse behavior.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `process.env` → service runtime | Untrusted at first read; zod is the gate; one consumer per service (`config/defaults.ts`) |
| `.env` file → committed git | `.env` is gitignored; `.env.example` is committed and carries dev defaults only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01.7-01 | Tampering | Service silently runs with malformed env (e.g., `BET_MIN_CENTS=abc`) | mitigate | Zod fail-fast at module load; service crashes at boot before any HTTP/AMQP traffic |
| T-01.7-02 | Information Disclosure | Real secrets accidentally committed in `.env` | mitigate | `.gitignore` covers `.env`, `.env.local`, `.env.*.local`; verified by `git check-ignore` in Task 3 |
