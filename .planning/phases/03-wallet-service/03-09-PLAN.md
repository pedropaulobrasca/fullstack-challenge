|-----------|----------|-----------|-------------|-----------------|
| T-03-31 | Tampering | Test pollution (one test leaves rows that break the next) | mitigate | resetWalletsSchema helper truncates the four phase-3 tables (transactions, wallets, outbox, inbox) in FK-aware order between tests |
| T-03-32 | Information Disclosure | Test JWT signing key persisted to disk | accept | mintTestJwt uses an in-process ephemeral RSA key pair; never persisted; lifespan = test process |
| T-03-33 | Spoofing | Token re-use across test runs causing stale state | mitigate | Each test mints a fresh JWT with current iat + exp; no cross-test sharing |
| T-03-34 | Repudiation | Smoke probe 25 fails on a re-run because the wallet already exists with mutated balance | accept | Probe records the actual balance and asserts equality; if previous test mutated state, the operator re-runs `bun run docker:prune` per the SUMMARY note |
