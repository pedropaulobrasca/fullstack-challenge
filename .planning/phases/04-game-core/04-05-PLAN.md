<objective>
Ship the hash-chain bootstrap service that runs once on first application boot, generates 1M chain entries via the pure-function `generateSeedChain` from `@crash/contracts/provably-fair`, and persists them via `SeedChainRepository.insertChain`. Idempotent: on every subsequent boot, the service short-circuits when `countEntries() > 0`. Plus the GameCoreModule that wires all three repositories into DI.

Purpose: REQ-FAIR-01 — the pre-generated hash chain is the IMMUTABLE COMMITMENT story: chain[0]'s hash is published; once anyone has saved it, the operator cannot pick a new seed. Re-generating on every boot breaks the commitment. Research §Pitfall 7 documents this exact failure mode and the idempotent `countEntries() > 0` check is the defense.

Output: SeedChainBootstrap @Injectable + GameCoreModule with repository DI bindings + AppModule wiring. Round loop service consumes the seed chain in Plan 04-06.
</objective>
