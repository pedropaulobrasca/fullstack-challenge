| T-04-07-01 | Spoofing | Forged JWT | mitigate | jose.jwtVerify validates issuer + audience + signature against cached JWKS |
| T-04-07-02 | Tampering | Token replay after revocation | accept | Keycloak short-lived access tokens (default 5min); no revocation list in v1; documented in ADR-012 |
| T-04-07-03 | Information Disclosure | JWKS cache poisoning | mitigate | cacheMaxAge=600s, cooldownDuration=30s — jose validates JWKS against signature, not URL alone |
| T-04-07-04 | Denial of Service | JWKS endpoint flapping | mitigate | cooldownDuration=30s prevents rapid refetch on transient errors |
