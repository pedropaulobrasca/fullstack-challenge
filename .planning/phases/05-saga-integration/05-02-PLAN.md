<objective>
Add `RoundLoopService.getMultiplierAt(at: Date): Multiplier` — a pure function reading the in-memory live round + env.GROWTH_RATE and returning the server-authoritative multiplier value at the supplied instant. This is the cashout-multiplier source consumed by plan 05-06's `CashOutUseCase` and (forward-compatible) Phase 6's WS gateway. Method is pure: no I/O, no DB read, no caching of the last tick.

Purpose: Server-clock authority over cashout (Pitfall C2 prevention). Multiplier MUST be computed at the controller's first line `new Date()` BEFORE any await — and that requires a synchronous, in-memory lookup, which means RoundLoopService must keep the current Round + startedAt accessible.

Output: Pure `getMultiplierAt` method + unit tests covering BETTING (throws), RUNNING (computes), CRASHED (caps at crashPoint), pre-startedAt (throws or returns 1.00x — see action).
</objective>
