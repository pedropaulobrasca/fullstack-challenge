Land the background sweeper that drives REQ-SAGA-03: "after `SAGA_TIMEOUT_MS=5000` without a Wallet reply, the Bet is auto-refunded." The sweeper polls `bet_saga_state` for expired DEBIT_PENDING rows via `FOR UPDATE SKIP LOCKED LIMIT 100` (Phase 10 scale-out forward-compatible per ADR-017 carry-forward), then for each row atomically transitions the Bet to REFUNDED, the saga to TIMED_OUT, and writes a `bet.refunded` envelope to the game-events outbox. The compensation branch (late `wallet.debited` arriving AFTER the sweeper has refunded) is already handled by `WalletDebitedHandler` from plan 05-05 — sweeper + compensation together close the failure mode where Wallet succeeded but games didn't see the reply in time.

Output: SagaTimeoutSweeper service with recursive setTimeout schedule (mirroring `RoundLoopService` shape per ADR-017), env constant addition, module registration, unit tests covering the race-lost branch.

    1. Create `saga-timeout-sweeper.service.ts`:
       ```ts
       @Injectable()
       export class SagaTimeoutSweeper implements OnApplicationBootstrap, OnApplicationShutdown {
         private readonly log = new Logger(SagaTimeoutSweeper.name);
         private timer: ReturnType<typeof setTimeout> | null = null;
         private running = false;

         constructor(
           private readonly em: EntityManager,
           private readonly outbox: OutboxRepository,
           @Inject(BET_SAGA_REPOSITORY) private readonly sagas: BetSagaStateRepository,
           @Inject(BET_REPOSITORY) private readonly bets: BetRepository,
         ) {}

         async onApplicationBootstrap(): Promise<void> {
           this.running = true;
           this.scheduleAt(env.SAGA_SWEEP_INTERVAL_MS);
         }

         async onApplicationShutdown(): Promise<void> {
           this.running = false;
           if (this.timer) { clearTimeout(this.timer); this.timer = null; }
         }

         // Public for unit-test invocation; idempotent on each call.
         async sweep(): Promise<void> { /* see step 2 */ }

         private scheduleAt(ms: number): void {
           if (!this.running) return;
           this.timer = setTimeout(() => {
             this.sweep()
               .catch((err) => this.log.error('saga sweep failed; will retry', err instanceof Error ? err.stack : String(err)))
               .finally(() => this.scheduleAt(env.SAGA_SWEEP_INTERVAL_MS));
           }, Math.max(0, ms));
         }
       }
       ```

       ```ts
       await this.em.transactional(async (txEm) => {
         const expired = await this.sagas.claimExpired(100, new Date(), txEm);
         for (const saga of expired) {
           const refunded = await this.bets.tryTransition(saga.betId, 'PENDING', 'REFUNDED', { refundReason: 'SAGA_TIMEOUT' }, txEm);
           if (refunded === null) { this.log.warn(`saga ${saga.betId}: bet no longer PENDING during timeout sweep — skipping`); continue; }
           const transitioned = await this.sagas.transition(saga.betId, 'DEBIT_PENDING', 'TIMED_OUT', txEm);
           if (transitioned === null) { this.log.warn(`saga ${saga.betId}: saga no longer DEBIT_PENDING — skipping outbox`); continue; }
           await this.outbox.add(
             buildEnvelope({
               type: 'bet.refunded',
               version: 1,
               correlationId: saga.correlationId,
               causationId: saga.correlationId,
               payload: { betId: saga.betId, reason: 'SAGA_TIMEOUT' },
             }),
             { exchange: EXCHANGES.GAME_EVENTS, routingKey: 'bet.refunded', aggregateType: 'Bet', aggregateId: saga.betId },
             txEm,
           );
         }
       });
       ```
