<objective>
Build the center-stage Canvas curve renderer (REQ-FE-02) and the local multiplier compute + EWMA server reconciliation (REQ-FE-03) — the single most craft-judged surface of the project. The curve runs a 60fps `requestAnimationFrame` loop with `devicePixelRatio` scaling and per-frame `clearRect`, computing the multiplier locally from the same `@crash/contracts` `multiplierAt` formula anchored to `roundStartedAt`, tweening toward the server tick via EWMA clock-offset (never snap), and freezing on the server-authoritative crash value.

Critical disciplines (CLAUDE.md §Frontend, D-05/D-06):
- Canvas 2D only (rAF + dPR + clearRect) — NO SVG, NO WebGL.
- Local compute uses the imported `multiplierAt` (byte-identical to server) anchored to `roundStartedAt`; reconciliation adjusts only the clock offset via EWMA `VITE_EWMA_ALPHA` — it never overwrites the displayed value with the raw tick (no snap, Pitfall 4).
- The loop touches ONLY `multiplier.store` (D-06) so panels/feed/history never re-render at 60fps.
- Crash freeze uses the server `crashValue` from `round.store`, not the last interpolated frame.

Purpose: deliver the rising emerald→cyan curve with restrained glow, the central live multiplier, and the crash freeze — the visual core of the slice.
Output: `local-multiplier.ts` pure compute + test; `use-raf-curve.ts` rAF/EWMA loop; `draw-curve.ts` pure Canvas drawing; `crash-curve.tsx` canvas component + dPR sizing + test (jsdom-mocked canvas).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server tick → client display | Ticks reconcile the clock offset only; the displayed value is locally computed, server crash value is authoritative for freeze |
| Client interpolation → crash decision | Interpolation is cosmetic; it never determines win/loss (server-authoritative, ADR-023) |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07-15 | Tampering | Re-deriving the multiplier formula on the client (drift from server) | mitigate | Import `multiplierAt` from `@crash/contracts` — one formula, FORMULA_VERSION shared; never reimplement (Pitfall: formula drift) |
| T-07-16 | Tampering | Freezing on local interpolation instead of server crash value | mitigate | Crash freeze writes `round.store.crashValue` (server-authoritative), not the last frame (Pitfall 4) |
