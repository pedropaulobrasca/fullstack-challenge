<objective>
Build the two streaming-list surfaces: the live bet/cashout feed with own-action highlight (REQ-FE-07) and the last-20 color-banded crash history strip (REQ-FE-08). Both render from state landed in 07-04 (`feed.store` circular buffer + `use-history`/history list); this plan adds only the rendered UI + the pure color-band classifier.

Disciplines:
- Color semantics (D-02): own-action accent = emerald/cyan; history high band = emerald, mid = amber `#F59E0B`, low = red `#EF4444` (shares the crash hue — semantically "bad outcome", acceptable per UI-SPEC). Red is NOT used for anything else.
- History thresholds are config-driven (`VITE_HISTORY_RED_MAX_X` / `VITE_HISTORY_YELLOW_MAX_X`) — never hardcoded (CLAUDE.md §Configuration).
- Chips use Fira Code tabular (14px Label role) so `1.04x` and `12.50x` align (UI-SPEC Typography).
- The feed is a `scroll-area` capped to the buffer; newest first; masked player ids use `muted-foreground`.

Purpose: deliver the "social proof" rails that make the round feel alive and the at-a-glance recent-volatility read.
Output: `history-band.ts` pure classifier + test; `history-strip.tsx`, `live-feed.tsx`, `feed-row.tsx` components + a feed test (own-highlight + cap + empty state).
</objective>
