Refactor `frontend/src/features/curve/use-raf-curve.ts` to accept an optional `driver: RafCurveDriver` parameter while preserving every Phase 7 caller's existing behavior (default driver = the current store-reading closure). This is the load-bearing seam for D-05 (replay reuses the production renderer); per RESEARCH Pattern 2, the replay modal in Plan 08-07 supplies a deterministic time-stepper driver, so `draw-curve.ts` stays untouched and there is no separate playback code path.

Purpose: REQ-REPLAY-03 mandates renderer reuse (no separate code path); REQ-REPLAY-01 byte-for-byte determinism requires the same `multiplierAt` math to drive both live and replay frames through the same draw function.

Current signature (frontend/src/features/curve/use-raf-curve.ts):
- `export type CurveFrame = { multiplier: number }`
- `export function useRafCurve(onFrame?: (frame: CurveFrame) => void): React.MutableRefObject<CurveFrame>`
- Live behavior: rAF loop reads useRoundStore (status, roundStartedAt, crashValue) + useMultiplierStore (serverOffsetMs), computes `localMultiplier(roundStartedAt, baseOffset)`, writes via useMultiplierStore.setRendered + frameRef + onFrame.

- Lifecycle subscribes to useRoundStore status transitions to re-arm/cancel rAF.

Phase 7 caller (frontend/src/components/crash-curve.tsx): invokes `useRafCurve((frame) => { draw(frame.multiplier, ...); })` with NO driver arg — must keep working.

New seam to add (per RESEARCH Pattern 2):
- `export type RafCurveDriver = { multiplier: () => number; status: () => RoundStatus | "RUNNING" | "CRASHED" | "BETTING" | "SETTLED"; crashValue: () => number | null; shouldStop: () => boolean }`
- `export function useRafCurve(onFrame?: (frame: CurveFrame) => void, driver: RafCurveDriver = liveDriver): ...`
- `liveDriver` is the module-level constant whose methods wrap the existing useRoundStore/useMultiplierStore getter logic.
- When `driver !== liveDriver` the hook MUST NOT call `useMultiplierStore.getState().setRendered(...)` (avoid corrupting the live store from a replay session).
