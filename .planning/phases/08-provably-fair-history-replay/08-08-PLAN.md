<objective>
Phase 8 ROADMAP success criterion 4: "A deterministic-replay E2E test reproduces a captured live round and asserts the rendered multiplier values byte-match the original frame samples — proving the renderer and fairness algorithm are the single source of truth."

Implement this as a Vitest unit test that samples `multiplierAt(growthRate, t)` at a fixed grid of `t` values (NOT rAF callbacks — per RESEARCH Pitfall 7, vsync drift makes rAF sampling flaky) along two paths:

1. **Live derivation path**: directly call `multiplierAt(t, growthRate)` for each grid point — this is what the live `localMultiplier` reduces to.
2. **Replay derivation path**: feed the same `(growthRate, crashPoint)` into `sampleReplayMultiplier({startedAtWall: 0, speed: 1, paused: false, ...}, t)` for each grid point.

Assert the two arrays are byte-identical (`expect(samples1).toEqual(samples2)`). Additionally, sweep speeds 1, 2, 4 to assert `sampleReplayMultiplier(state@speed=2, t) === sampleReplayMultiplier(state@speed=1, 2*t)` — proving D-03's "speed only changes wall-clock rate, not the underlying simulation grid" contract.

Anchor the test to the Phase 4 locked-byte fixture (the same fixture exercised by Plan 08-01's oracle test) so a future regression in either the formula or the driver is caught here even before the formula's own test fires.

Purpose: REQ-REPLAY-01 (byte-for-byte reproduction); Phase 8 ROADMAP success criterion 4 (deterministic replay E2E proof).

Output: One Vitest test file + a fixture file; the test runs in <2s; no Playwright dependency; no browser context needed (jsdom is enough since both paths reduce to pure math).
</objective>
