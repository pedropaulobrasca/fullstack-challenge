## Layout Contract (3 new surfaces)

### Surface A — Fairness Badge (fills the header slot Phase 7 reserved)

Rendered in `__root.tsx` header, right of `BalancePill`, left of the user menu / login redirect.

```
┌──────────────────────────────────────────────────────────┐
│ [logo] [history strip top]                               │
│                                                          │
│            …                            [Fairness ✔ ●]   │ ← THIS
│                                       [BalancePill] [user]│
└──────────────────────────────────────────────────────────┘
```

- shadcn primitive: shadcn `Button` (variant=`outline`, size=`sm`) — clickable to open the Sheet. `Tooltip` wrapping for `aria-label="Open fairness verification panel"`.
- Content: lucide `ShieldCheck` icon (16px, accent) + **"Fairness"** label (Fira Sans 14px semibold) + an inline 8×8 emerald pulse dot signalling "commitment live". When no current round (e.g. between `CRASHED`/`SETTLED` ↔ `BETTING`), the dot dims to muted; the button stays clickable.
- Hit area: ≥ 44 × 44px (touch target rule).
- On click: opens the verification Sheet (Surface B).
- States:
  - **commitment present** (current round in BETTING or RUNNING with `seedHash` available): full accent treatment.
  - **between rounds** (no current seedHash): dot dims to `muted-foreground`; tooltip swaps to "Waiting for next round commitment". Sheet still openable to inspect the prior round.
  - **previous round verified=MATCH** (most recent revealed serverSeed hashed locally and matched the prior commitment): tiny `CheckCircle2` checkmark replaces the dot for 4s after a fresh `round:crashed`, then fades back to the live dot.

## Accessibility & Real-Time Discipline (Phase 8 specifics)

- **Verdict never communicated by color alone** (MCP "Color Only" sev:High, Result 5): every verdict combines icon (`CheckCircle2` / `XCircle`) + text (`MATCH` / `MISMATCH`) + color. Screen-reader users get the same evidence as sighted users via `role="status"` + `aria-live="polite"` (or `assertive` for the verify-route MISMATCH).
- **Focus management is shadcn-native** (MCP "Maintain focus management" sev:High): both Sheet and Dialog trap focus, restore on close. Do NOT custom-handle focus.
- **Visible focus rings** (MCP "Focus States" sev:High): inherits the Phase 7 ring token; all new interactive elements (Fairness button, Copy buttons, speed toggles, Play/Pause, Replay chip) show focus rings on keyboard nav.
- **Touch targets ≥ 44px** (MCP "Touch Target Size" CRITICAL): every new interactive element (Fairness badge, history-chip whole-tile, Copy buttons, Play/Pause, ToggleGroup items, Back-to-game link) meets the 44px hit-area rule. Visual sizes may be smaller, padding supplies the rest.
- **Reduced motion** (MCP sev:High): all Phase 8 entrances/exits snap under `prefers-reduced-motion: reduce`. The dot pulse stops. The Phase 7 juice budget is inherited as-gated.
- **Hash content readability**: Fira Code 14px regular, `word-break: break-all`, `letter-spacing: 0`. On mobile, 64-hex wraps to 2 lines inside the `HashBlock` without truncation. Truncation (`a3f8…d92e`) is shown only in tooltips / chip labels, never inside the verification surfaces.
- **Live region for fetch+compute**: drawer and verify page wrap the computed-hash + verdict slot in `aria-live="polite"` so screen readers announce the result once.
- **Background game preserved** during overlay: the WS connection, the rAF loop, the round FSM keep running. Overlay is purely visual. This is the discipline that makes D-01 + D-02 defensible.
