## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| RabbitMQ game.events → projector | events arrive at-least-once; inbox dedupe is the trust gate |
| Projector → leaderboard_24h | single-row UPSERT per event, no cross-row contention |
