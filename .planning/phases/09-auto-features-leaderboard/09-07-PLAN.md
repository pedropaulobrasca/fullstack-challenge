## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → GET /games/leaderboard | unauthenticated requests rejected at JwtGuard; window param validated via Zod enum |
| Use case → repository | controlled internal call; window mapping is the only transform |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-40 | Information Disclosure | Endpoint leaks full player UUIDs to authenticated callers | mitigate | maskPlayerId applied in GetLeaderboardUseCase before serialization (first 8 hex only); contract schema regex enforces 8-hex shape at validation time. |
| T-09-41 | Tampering | Player forges window=all_time to bypass 24h cap | mitigate | Zod enum `z.enum(['24h'])` rejects any other value with 400 — single allowed value v1. Adding a new window (7d, all-time) in v2 requires schema + RESEARCH update. |
| T-09-42 | DoS | Player floods GET /games/leaderboard endpoint | accept | Endpoint is cheap (indexed query, LIMIT 10); rate limiting is Phase 10 work per Stretch backlog REQ-STRETCH-07. Authenticated requests only — limits abuse to logged-in players. |
| T-09-43 | Access Control | Endpoint returns one player's private data to another | mitigate | Endpoint returns the SAME top-N to every authenticated caller — there is no per-player slice. Own-row highlight is FE-only (the FE knows its own playerId). |
| T-09-44 | Information Disclosure | netProfit serialized as raw number leaks bigint precision | mitigate | MoneySnapshot serialization preserves bigint precision via `amount: string`; contract schema rejects raw number; controller uses Money.toSnapshot. |
</threat_model>
