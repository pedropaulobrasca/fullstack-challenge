- `new OTLPTraceExporter({ url })` — `url` should end with `/v1/traces`

- `resourceFromAttributes({ [ATTR_SERVICE_NAME]: ..., [ATTR_SERVICE_VERSION]: ... })`

- `OpenTelemetryModule.forRoot({ metrics: { hostMetrics: false, apiMetrics: { enable: true } } })`
